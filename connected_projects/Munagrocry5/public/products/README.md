# Munna Mobile & Grocery - Product Repository Images

This folder houses category-structured local product images served directly from the store's repository and domain (`https://munagrocery.in/products/<category>/<ean>.jpg`).

## Folder Structure:
- `Atta/` - Wheat flour, Maida, Besan
- `Baby_Care/` - Baby food, diapers, wipes
- `Bath_Soap/` - Bathing soaps, body washes
- `Biscuits/` - Biscuits, cookies, rusks
- `Detergent/` - Washing powder, detergent bars, dishwash
- `Edible_Oil/` - Cooking oils
- `Hair_Care/` - Shampoos, conditioners, hair oils
- `Mobile_Accessories/` - Screen protectors, covers, chargers
- `Mustard_Oil/` - Mustard oils (Freedom, Engine, etc.)
- `Nutritional_Drinks/` - Horlicks, Boost, Bournvita, Complan
- `Oral_Care/` - Toothpaste, toothbrushes
- `Rice_Bran_Oil/` - Rice bran oils
- `Spices/` - Haldi, Mirch, Garam Masala
- `Tea/` - Leaf & Dust teas
- `General/` - General grocery items

## Naming Convention:
`<ean>.jpg` (e.g. `8901491101837.jpg`)
